# Security review, 2026-11-04

Focused source review of `apps/web` and its data paths after M2–M5 (local): GitHub App OAuth, token storage and refresh, sessions, CSRF, Drizzle queries, the public recap page, the PNG/OG card, and secrets. Two passes: the maintainer's agent, plus an independent reviewer given only the code. Every claim was checked against source; where possible it was reproduced locally with dummy data. No critical or high findings.

## Checked and ruled out

OAuth state and PKCE handling and login CSRF, open redirects, CSRF on route handlers (Origin check) and server actions (Next's built-in check plus session re-read), IDOR through `/u/[login]` (inner join on `recap_shares`), SQL injection (the `sql` templates only interpolate columns and bound parameters), XSS sinks, tokens or secrets in client bundles, private names in the card, OG image or client props, and secrets in git history (no token, key or client secret in any commit).

## Resolved after the review

- **Rate limiting at the edge** (2026-11-05): a Vercel Firewall rule allows 60 requests per 60 seconds per IP on paths starting with `/api` or `/u/` and answers 429 beyond that. Tested: 60 requests passed, the next 5 got 429, other pages were unaffected. See the deployment guide.

- **GCM tag rejection on Node** (2026-11-06): CI's "Token crypto on Node" job runs `scripts/check-crypto-node.mjs` on Node 24, the runtime production uses. A tampered full-length tag, a tampered ciphertext, a 4-byte tag and the wrong key all fail to decrypt.
- **Sign out everywhere** (2026-11-06): Settings → Devices → "Sign out on all devices" deletes every session of the account, the current one included, and clears the cookie. Signing in again still leaves other sessions alone, by design: revoking them is the user's explicit choice. Tested locally: a plain sign-out removed one of three sessions, sign-out everywhere removed the rest, other accounts' sessions were untouched, and a cross-origin request got 403.
