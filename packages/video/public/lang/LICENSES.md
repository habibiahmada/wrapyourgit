# Language logos

SVG icons from [Devicon](https://github.com/devicons/devicon) v2.16.0, MIT License,
Copyright (c) 2015 konpa. The logos themselves are trademarks of their respective owners and are
used only to identify the language next to the user's own statistics.

Mapped from GitHub's language names in `packages/video/src/languages.ts`. Languages without an
icon fall back to a badge in the language's GitHub colour.

Blade, Laravel's template language, has no logo of its own; it uses Devicon's Laravel logo
(`laravel.svg`, from `icons/laravel/laravel-original.svg`), as editors do.
